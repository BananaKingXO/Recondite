**Recondite** adds elemental spellbooks that are able to found and crafted in the new structures. These spellbooks are able to be upgraded with resources like ink, which makes the spellbooks stronger and more powerful!

-------
Features
-------
- Several Themed Spellbooks (As of right now, 3)
- New Resources
- New Randomly Generated Structures
- More to come!

-------
Notes
-------
- This datapack is still under development and bugs should be expected. The existing spellbooks are not finished and should be expected to not be fully functional. Please report any bugs or issues you encounter, this lets us (mostly me) improve the datapack and make the player experience better.
